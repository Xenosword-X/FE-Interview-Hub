什麼是 Event Loop？請說明 Call Stack 與 Task Queue 的關係
JavaScript 是單執行緒語言，Event Loop 是讓 JS 處理非同步操作的核心機制，由 Call Stack、Web APIs 與 Task Queue 三部分組成。
console.log('1') setTimeout(() => console.log('3'), 0) Promise.resolve().then( () => console.log('2') ) // 1 → 2 → 3
Call Stack 清空後，Event Loop 先清空所有 Microtask，再取一個 Macrotask 執行。

導覽模式切換

TOC 右欄

AI 輸入框
桌面嵌在文章底部。手機改為 sticky bottom bar，隨時可輸入，不需滾到底部，send 按鈕 44×44px。
Bottom Navigation
手機獨有，4 個 Tab（首頁/題庫/AI面試/我的），圖示 + 文字標籤，符合 ui-ux-pro-max bottom-nav-limit ≤5 規則。
排版優化
