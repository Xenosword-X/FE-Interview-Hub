什麼是 Event Loop？請說明 Call Stack 與 Task Queue 的運作機制
AI 練習作答

核心概念

JavaScript 是單執行緒（Single-threaded）語言，同一時間只能執行一件事。Event Loop 是讓 JS 能處理非同步操作的核心機制，由以下幾個部分組成：

重點：Event Loop 本身不在 JS 引擎中，而是由執行環境（瀏覽器 / Node.js）提供的機制。

1. Call Stack（呼叫堆疊）

同步程式碼的執行區域，採用 LIFO（後進先出）結構。函式被呼叫時推入，執行完畢後彈出。

2. Web APIs / Node APIs

處理 setTimeout、fetch、DOM 事件等非同步操作的環境 API。

3. Task Queue（巨集任務佇列）

非同步回呼（如 setTimeout callback）完成後排隊的地方，等待 Call Stack 清空後執行。

JavaScript 複製
// 範例：理解執行順序 console.log('1. 同步開始') setTimeout(() => { console.log('3. 巨集任務（setTimeout）') }, 0) new Promise((resolve) => { resolve() }).then(() => { console.log('2. 微任務（Promise.then）') }) // 輸出順序：1 → 2 → 3

Microtask vs Macrotask

除了 Task Queue，還有優先層級更高的 Microtask Queue（微任務佇列）：

  • Microtask：Promise.then、queueMicrotask、MutationObserver
  • Macrotask：setTimeout、setInterval、I/O 事件

每次 Call Stack 清空後，Event Loop 會先清空所有 Microtask，再取一個 Macrotask 執行。
